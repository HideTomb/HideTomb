## 👋 关于我 / About Me

> 你好，我是 **HideTomb（HoaxNas）**，一名专注于 **AI / Agent 应用** 与 **企业级内部工具** 的全栈开发者。热衷于把重复性工作交给 Agent，让人专注于创造。

- 🤖 **AI / LLM 应用**：基于 vLLM、Gemma 等开源模型，构建 Agent 协同平台、知识库检索（RAG）与流式对话系统
- 🌐 **全栈开发**：Python（FastAPI / Flask）后端 + Vue / 原生 JavaScript / TypeScript 前端
- 🧩 **Agent 生态**：MCP（Model Context Protocol）、nanobot 引擎、人与 Agent 协同工作流
- 🛠️ **DevOps / 运维**：Docker、systemd、Nginx、多环境（dev / test / prod）部署与自动化
- 📄 **知识管理**：HTML / Markdown 文档平台、全文检索、AI 摘要与质量评级
- 🎯 相信「人 + AI」协同能成倍放大生产力

## 🔥 精选项目 / Featured Projects

### 🌊 Nexus OS（智屿 OS）
浏览器内「人与 Agent 协同工作平台」：左侧 Chat Panel 对话、右侧 Doc Browser 文档代理，深度融合内部知识库，全程中文交互。
- `Python · FastAPI` `Vanilla JS` `SQLite` `SSE 流式`
- SSE 流式回复、思考模式（中文推理）、@ 引用文档、知识库五档检索、产出工作台

### 📚 md-host（智享）
内网 HTML / Markdown 文档托管平台，同时面向人类与 AI Agent。
- `Python · FastAPI` `SQLite FTS5` `Go CLI` `MCP`
- 全文搜索、版本历史、AI 摘要与质量评级、审计日志、Docker 部署、541 项测试

### 📊 天维·智呈（project-work-summary-pro）
AI 驱动的项目工作报告智能体，输入工作内容自动生成结构化报告。
- `Python · Flask` `JavaScript` `ECharts` `Vue 3`
- Web / GUI / CLI 三种方式，图表分析、对话式修改、批量生成、报告对比、管理驾驶舱，输出 HTML / Word / PPT / PDF

### 🔐 SVN_User（SVN 账号开通系统）
新员工 SVN / VPN 账号一键开通 + 邮件通知。
- `Vue` `Python · Flask` `Windows Agent`
- Web 界面 + CLI，自动写入 htpasswd 并发送开通邮件
